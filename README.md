# 🌸 عطور أحد | Ohod Perfumes (Next.js & Admin Panel)

متجر **عطور أحد (Ohod Perfumes)** تم بناؤه باستخدام أحدث تقنيات **Next.js 16 (App Router)**، **TypeScript**، **Tailwind CSS**، مع **لوحة تحكم إدارية شاملة (Admin Control Panel)** تمكنك من إضافة وحذف وتعديل أي شيء في المتجر.

---

## ✨ المميزات الرئيسية للمشروع

### 1. واجهة المتجر (Storefront):
- **تصميم فاخر متجاوب بالكامل (RTL)** متوافق مع الهواتف الذكية والأجهزة اللوحية والكمبيوتر.
- **كتالوج حقيقي كامل:** تم استخراج وتضمين جميع منتجات الموقع الأصلي (98 عطراً) بكافة التفاصيل (الأسماء العربية، النوتات والوصف، الأسعار، العروض، والصور الأصلية المحملة محلياً).
- **أقسام وتصنيفات كاملة:** (عطور رجالية، عطور نسائية، عطور للجنسين، عطور عساف، عطور القرشي، معطرات جو، بخور، سبراي، عروض وخصومات).
- **بحث فوري وفلاتر متقدمة:** بحث بالاسم والوصف، تصفية حسب القسم، تصفية المتوفر بالمخزن فقط، وترتيب حسب السعر أو نسبة الخصم.
- **سلة مشتريات تفاعلية (Cart Slide-over Drawer):**
  - حفظ السلة في المتصفح تلقائياً (`localStorage`).
  - زيادة/تقليل الكمية، حذف المنتجات، وحساب الإجمالي المباشر.
- **صفحة تفاصيل العطر (`/products/[id]`):**
  - معرض صور متعدد مع اختيار الصور المصغرة.
  - تفاصيل النوتات والثبات والتركيز.
  - حساب وتوضيح نسبة الخصم والتوفير.
  - عطور مشابهة ومقترحة من نفس القسم.
- **صفحة إتمام الطلب الشاملة (`/checkout`):**
  - التحقق من صحة رقم الهاتف المصري (010, 011, 012, 015).
  - قائمة منسدلة بـ 27 محافظة مصرية مع حساب مصاريف الشحن التلقائية الخاصة بكل محافظة.
  - الدفع عند الاستلام (Cash on Delivery).
- **صفحة نجاح الطلب (`/success`):**
  - رقم الطلب وتفاصيل العميل والشحن.
  - زر تأكيد فوري عبر تطبيق **واتساب** برسالة جاهزة.

---

### 2. لوحة التحكم الإدارية المتكاملة (`/admin`):
- **📊 لوحة القيادة (Dashboard):**
  - إجمالي المبيعات، عدد الطلبات، الطلبات الجديدة، إجمالي العطور، وتنبيهات العطور التي نفذت كميتها.
- **🧴 إدارة العطور والمنتجات:**
  - **إضافة عطر جديد:** (الاسم، القسم، السعر الأساسي، السعر بعد الخصم، الوصف، رابط الصورة، وحالة التوفر).
  - **تعديل أي عطر موجود:** تعديل كافة بياناته وأسعاره وصوره في أي وقت.
  - **تبديل حالة التوفر بضغطة زر واحدة:** (متوفر في المخزن / نفذت الكمية).
  - **حذف أي عطر نهائياً.**
- **🏷️ إدارة الأقسام والتصنيفات:**
  - إضافة فئات وأقسام جديدة للمتجر.
  - تعديل الأسماء أو حذف الأقسام مع فحص الأمان (منع حذف قسم يحتوي على منتجات).
- **📦 إدارة طلبات العملاء:**
  - عرض تفاصيل كل طلب بالكامل (الاسم، الهاتف، المحافظة، العنوان التفصيلي، الملاحظات، والعطور المطلوبة بالصور والكميات).
  - تحديث حالة الطلب الفورية: (`قيد المراجعة` ⬅️ `جاري التجهيز` ⬅️ `جاري الشحن` ⬅️ `تم التوصيل` ⬅️ `ملغي`).
  - زر مراسلة العميل عبر **واتساب** مباشرة بضغطة زر واحدة.
  - زر اتصال هاتفي مباشر بالعميل.
  - حذف وإلغاء الطلبات.
- **🚚 إدارة أسعار الشحن والمحافظات:**
  - تعديل مصاريف الشحن لأي محافظة من الـ 27 محافظة مصرية وحفظها فورياً.
- **⚙️ إعدادات المتجر العامة:**
  - تعديل اسم المتجر، الوصف، رقم الهاتف، رقم الواتساب.
  - تعديل وتفعيل/إيقاف الشريط الترويجي العلوي (Announcement Bar).
  - تعديل روابط التواصل الاجتماعي (فيسبوك، انستغرام، تيك توك).

## 🚀 طريقة التشغيل

### 1. تشغيل بيئة التطوير (Development):
```bash
cd don-perfumes
npm run dev
```
ثم افتح في متصفحك: [http://localhost:3000](http://localhost:3000)

### 2. الدخول إلى لوحة التحكم الإدارية:
افتح الرابط: [http://localhost:3000/admin](http://localhost:3000/admin)

### 3. بناء النسخة للإنتاج (Production Build):
```bash
cd don-perfumes
npm run build
npm run start
```

## 🗄️ بنية حفظ البيانات (Database & Persistence)
يتم حفظ كافة البيانات في ملف `don-perfumes/data/store.json` تلقائياً ومحلياً:
- عند إجراء أي إضافة، تعديل، أو حذف في لوحة التحكم، يتم تحديث الملف فوراً دون الحاجة لقواعد بيانات خارجية معقدة.
- يمكنك عمل نسخة احتياطية من الملف بسهولة أو نقله لأي استضافة (Vercel, VPS, Railway, etc.).
